# bond_bot — правила для Claude

Telegram-бот игры «Шпион». Играют вживую за одним столом, бот открыт **в личке хоста на
одном телефоне**. Подробности — `.claude/rules/`.

## ПЕРЕД ЛЮБЫМ ИЗМЕНЕНИЕМ
1. Прочитать существующий код (Read). Не догадываться.
2. Понять, что он делает сейчас.
3. Изменить **только** то, о чём попросили.

## ЗАПРЕЩЕНО

**Докстринги и комментарии.** В проекте их 0. Прямое требование владельца.
```python
# WRONG                                    # RIGHT
def max_spies(count: int) -> int:          def max_spies(count: int) -> int:
    """Максимум шпионов."""                    return count - 1
    return count - 1  # минимум 1 мирный
```

**Импорты aiogram или sqlalchemy в `domain/`.** Движок игры не знает про Telegram и БД.
```python
# WRONG (в domain/engine.py)               # RIGHT
from aiogram.types import Message          def start_game(theme: ThemeSnapshot, ...)
from bond_bot.infrastructure...import Theme
```

**Чтение связей у объекта, добавленного в этой же сессии** (и `session.get(Theme, ...)`,
который вернёт его же из кеша незагруженным) → `MissingGreenlet`. Ловушка сработала дважды.
```python
# WRONG                                    # RIGHT
session.add(theme); await session.flush()  await session.scalars(
theme.words                                    select(Word).where(Word.theme_id == theme.id))
```

**Пользовательский текст в HTML без `html.escape()`.** Тема с `&` в названии перестанет
открываться: Telegram отвергнет разметку.
```python
# WRONG                                    # RIGHT
f"📗 <b>{name}</b>"                        f"📗 <b>{escape(name)}</b>"
```

**`message.answer()` в сценарии партии.** Слово останется в истории — подсмотрят.
```python
# WRONG                                    # RIGHT
await callback.message.answer(card)        await callback.message.edit_text(card, ...)
```

**Относительные импорты, `print()`, `pip install`.** Ноль вхождений каждого.
Зависимости — `poetry add`.

## ОБЯЗАТЕЛЬНО

- Аннотации типов на функциях (147 из 150) — `def f(x: int) -> str:`
- Тексты для пользователя — только в `presentation/texts.py`
- Весь SQL — только в `ThemeRepository`
- Каждый `callback_query`-хендлер завершается `await callback.answer()`
- Правка `domain/engine.py` → тест в `tests/test_engine.py`
- Правка модели в `infrastructure/database/models.py` → `poetry run alembic revision --autogenerate`
- Перед словами «готово»: `poetry run pytest` **и** `poetry run ruff check src/ tests/`

## АРХИТЕКТУРА

- `domain/` — чистые правила игры → `core/registry.py` — партии в памяти по `chat_id`
- `infrastructure/database/` — только темы и слова; партии в БД не пишутся
- `presentation/` — handlers → keyboards → texts; роутеры: `[menu, themes, game]`, порядок важен
- Вход: `__main__.py` → `init_db()` (= `alembic upgrade head`) → `seed_builtin_themes()`
  → `errors.register(dp)` → polling
- Деплой: `docker compose up -d --build`; volume на `/data` обязателен, иначе БД в слое
- Состояние партии меняет **только** `engine.py`, хендлеры фазу не присваивают

## ИНВАРИАНТЫ

1. **В `DOUBLE_AGENT` шпион не знает, что он шпион** — карточка как у мирных, кнопка
   «Шпион называет слово» отсутствует, `open_spy_guess()` бросает `GameError`.
   Сломать = сломать весь режим.
2. **Шпионов может быть большинство, но хотя бы один мирный обязан знать слово**
   (`max_spies = player_count - 1`). Не «чинить» до меньшинства — это решение владельца.
3. **Выбывший не голосует и не может быть целью** — иначе счёт голосов врёт.
4. **Порядок проверки конца игры**: сначала «все шпионы выбыли», потом «живых ≤ 2».
   Обратный порядок отдаёт победу не тем.
5. **Догадка шпиона необратима** — вердикт «угадал/не угадал» ставит хост, партия сразу
   `FINISHED`. Список слов шпиону не показывается: он назвал бы самое подходящее.
6. **Встроенные темы правит и удаляет только админ** (`settings.is_admin`), обычный игрок —
   нет. Любая правка ставит `is_customized=True`, и сид перестаёт синхронизировать эту тему
   с JSON: источник правды — база. Удаление встроенной темы **мягкое** (`is_deleted=True`):
   слова остаются, тема уходит в корзину и восстанавливается кнопкой. Сид ищет тему по
   `source_name` (имя из JSON), а не по `name` — поэтому переименование не создаёт дубликат.
   Пользовательские темы удаляются по-настоящему.
7. **Каталог открыт для всех без модерации** — это цель проекта, не упущение.

## НЕ РАЦИОНАЛИЗИРОВАТЬ

| Отговорка | Почему неверно |
|---|---|
| «Добавлю докстринг, так понятнее» | Владелец удалил все и запретил. Объяснять — в ответе, не в коде |
| «Шпионов больше половины — это баг» | Осознанное решение владельца, см. инвариант 2 |
| «Статистику/таймер/имена игроков полезно добавить» | Все три отклонены владельцем явно |
| «Проверю права только кнопкой» | Старый callback из истории обойдёт клавиатуру |
| «`session.get` быстрее» | Он и вызвал `MissingGreenlet` дважды. `select` намеренно |
| «Тесты потом» | `engine.py` тестируется за 0.02с, отговорки нет |
| «В существующем коде так же» | Существующие нарушения — техдолг, а не разрешение |
