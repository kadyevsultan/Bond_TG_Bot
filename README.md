# 🕵️ Шпион — Telegram-бот

Бесплатный бот для игры «Шпион» (Spyfall) без пейволлов, подписок и «премиум-тем».

---

## Зачем этот проект

Все существующие боты и приложения по «Шпиону» дают бесплатно одну тему — локации, — а всё
остальное прячут за платной подпиской: другие темы, свои слова, настройки игры.

Мы с друзьями хотели просто сесть и поиграть. С разными темами. Со своими словами.
Не думая о том, что нам можно, а что нельзя.

**Этот бот сделан ровно для этого: всё бесплатно, всё открыто, никаких ограничений.**

---

## Правила игры

Классический «Шпион»:

1. Компания получает общее слово из выбранной темы — например, `Якорь`.
2. Один или несколько игроков получают роль **шпиона**.
3. Все по очереди задают друг другу вопросы про загаданное слово.
4. Мирные пытаются вычислить шпиона, шпион — понять слово и не спалиться.
5. Голосование → кик → раскрытие.

---

## Как играем мы (формат бота)

Мы играем **вживую, за одним столом**. Обсуждение и споры идут голосом — бот не мешает,
он только раздаёт роли и ведёт голосование.

### Pass and Play — один телефон по кругу

Не нужно, чтобы у каждого был запущен бот. Телефон хоста обходит круг:

```
Игрок 1 → [Показать слово] → увидел → [Скрыть] → передал дальше
Игрок 2 → [Показать слово] → ...
```

Слово скрыто, пока игрок сам не нажмёт кнопку. После просмотра — снова скрыто.

**Кнопки жмёт хост.** Игра офлайн: игроки просто говорят вслух, за кого голосуют,
а хост отмечает это в боте. Телефон реально ходит по кругу только в двух местах —
раздача слов в начале и попытка шпиона угадать слово.

## Функционал

### 🎲 Игра

- **Pass and Play** — раздача ролей по одному телефону
- **Количество игроков** — задаётся при создании игры
- **Несколько шпионов** — 1, 2 и больше, на большую компанию
- **Два режима шпиона** (выбирается при создании игры):
  - `Классика` — шпион видит только «Ты шпион», слова не знает
  - `Двойной агент` — шпион получает **похожее слово** из той же темы
- **Без таймера** — голосуем когда захотим, бот не торопит

### 🗳 Голосование

Голосование идёт внутри бота, по кругу, тем же телефоном:

1. Бот спрашивает каждого игрока по очереди, за кого он голосует
2. Считает голоса и объявляет, кого выгнали
3. **Сразу говорит, был ли выгнанный шпионом**
4. Игра продолжается, пока в игре остаётся хотя бы один шпион

**Условия конца игры:**

| Событие | Итог |
|---|---|
| Выгнали всех шпионов | 🟢 Победа мирных |
| Осталось 2 игрока | 🔴 Бот раскрывает шпиона, победа шпионов |
| Шпион назвал слово верно | 🔴 Победа шпионов |
| Шпион назвал слово неверно | 🟢 Шпион раскрыт, победа мирных |

### 💬 Шпион называет слово

Шпион в любой момент может попытаться угадать слово. Чтобы не было споров и «я передумал»,
проверку делает сам бот:

1. Кто-то жмёт кнопку **«Шпион называет слово»**
2. Бот передаёт телефон шпиону и показывает **список всех слов темы**
3. Шпион выбирает свой вариант
4. Бот сравнивает и **сам объявляет исход** — угадал или нет

Так решение необратимо, и никому не надо верить на слово.

> В режиме `Двойной агент` шпион угадывает **настоящее слово мирных**, а не своё.

### ⚖️ Ничья при голосовании

Если голоса разделились поровну, бот показывает хосту выбор:

- **Переголосовать** — тот же круг заново
- **Выгнать всех**, у кого одинаковое число голосов
- **Дополнительный раунд** — вернуться к обсуждению, никого не кикаем

### 🚪 Выбывание

Выгнанный игрок **выбывает из игры**: больше не говорит и не голосует.
Бот исключает его из списка кандидатов на следующих голосованиях.

### 📚 Темы и слова

- **Готовые темы** из коробки — локации, профессии, еда, фильмы и т.д.
- **Свои темы** — создать, добавлять и удалять слова, редактировать

**Структура слова.** У каждого слова темы есть свой список похожих слов:

```
Тема «Кухня»
├── Нож  →  похожие: [Вилка, Ложка, Ножницы]
└── Чайник → похожие: [Кастрюля, Кружка]
```

В режиме `Двойной агент` шпион получает **случайное слово из списка похожих**.
Список пополняется по одному слову — добавить ещё вариант можно в любой момент.

Похожие слова **опциональны**: если у слова их нет, бот в режиме `Двойной агент`
берёт другое случайное слово из той же темы.
- **Открытый каталог** — все пользовательские темы видны всем, любой может взять чужую тему
  и играть с ней. Без модерации, без одобрений, без ожидания.
- **Админ-права** — у создателя бота есть возможность удалить мусорные темы из каталога

## Осознанно НЕ делаем

Чтобы бот оставался простым и не превращался в приложение:

- ❌ **Статистика и очки** — лишняя сложность, при игре вживую счёт и так на виду
- ❌ **Имена игроков** — игроки обезличены: «Игрок 1», «Игрок 2», ...
- ❌ **Таймер** — голосуем когда сами захотим
- ❌ **Онлайн-игра из разных мест** — бот заточен под живую игру за одним столом
