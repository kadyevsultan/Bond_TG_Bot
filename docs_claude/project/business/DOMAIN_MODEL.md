# Доменная модель

> Снято 2026-08-12. Машина состояний целиком — `.claude/rules/02-state-machines.md`,
> карта движка — `../architecture/GAME_ENGINE_MAP.md`.

## Продукт

Telegram-бот для настольной игры «Шпион» (Spyfall). Причина существования: во всех
существующих ботах и приложениях бесплатна одна тема (локации), остальное — по подписке.
Здесь бесплатно всё: 12 встроенных тем, неограниченные свои темы, открытый каталог.

Аудитория — компания друзей владельца, играющая вживую.

## Роли

| Роль | Кто это | Что может |
|---|---|---|
| Хост | Владелец телефона, у него открыт бот | Всё: создать игру, вести голосование, редактировать свои темы |
| Игрок | Сидит за столом, бота у него нет | Смотрит своё слово, когда телефон дошёл до него; говорит вслух |
| Админ | `ADMIN_IDS` из `.env` | Удалять чужие темы, править и удалять встроенные |

Бот знает только Telegram-аккаунт хоста. Остальные игроки для системы — номера 1..N.

## Сущности игры

| Сущность | Живёт | Ключевое |
|---|---|---|
| `Game` | в памяти, до конца партии | тема, загаданное слово, режим, игроки, фаза, голоса |
| `Player` | внутри `Game` | номер, шпион ли, слово на экране, выбыл ли |
| `Theme` / `Word` / `SimilarWord` | SQLite, постоянно | контент для игры |

## Жизненный цикл партии

```
создание (тема → игроки → шпионы → режим)
   → раздача по кругу
   → обсуждение вживую
   → голосование (по кругу, отмечает хост)
   → кик, объявление роли выбывшего
   → повтор обсуждения, пока жив хоть один шпион
   → финал: раскрытие слова и всех ролей
```

Партия не сохраняется: закончилась — удалена из реестра.

## Контентная модель

Тема содержит слова, у каждого слова свой список похожих. Похожие нужны только режиму
«Двойной агент»: шпион получает случайное слово из этого списка.

Свои темы приватны по владельцу, но **видны всем в каталоге** и доступны для игры и
копирования. Копия становится полноценной собственной темой копирующего.
