# Технический долг

> Снято 2026-08-12.

| Элемент | Severity | Стоимость | Рекомендация |
|---|---|---|---|
| Нет экранирования HTML | HIGH | ~30 мин | Общая функция форматирования + `html.escape` на всех пользовательских подстановках |
| Нет `Dispatcher.errors` | MEDIUM | ~20 мин | Хендлер ошибок: лог + «что-то пошло не так» + кнопка в меню |
| Alembic не заведён | MEDIUM | ~40 мин | Нужен до первого постоянного хостинга, иначе смена схемы = потеря БД |
| `presentation/middlewares/`, `presentation/filters/` пусты | LOW | — | Удалить или наполнить при появлении middleware ошибок |
| Дублирование проверки «тема без слов» | LOW | ~10 мин | Вынести в одну функцию-гард |
| Нет CI | MEDIUM | ~30 мин | `pytest` + `ruff` на push закрыли бы регрессии; сейчас всё вручную |
| Нет Dockerfile / systemd | MEDIUM | — | Отложено владельцем вместе с хостингом |
| `data/` не бэкапится | LOW | — | Пользовательские темы живут только в одном файле SQLite |

## Чего долгом НЕ является

Это осознанные решения, а не упущения — не «чинить»:

- Партии в памяти, а не в БД
- Отсутствие статистики, имён игроков, таймера
- Каталог без модерации
- Отсутствие докстрингов и комментариев
- Шпионов может быть большинство
