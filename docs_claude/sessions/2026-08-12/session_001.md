Проект прошёл путь от пустой папки (`main.py` на 0 байт) до играбельного бота:

## Решения и почему

| Решение | Почему |
|---|---|
| `src`-layout + entry point вместо `python main.py` | Запуск не зависит от рабочей папки, нет `sys.path` хаков, локально и на сервере импорты одинаковы |
| `domain/` без aiogram и sqlalchemy | 24 теста правил бегут за 0.02 с; правила можно менять, не трогая UI |
| Партии в памяти (`dict[chat_id, Game]`) | Игра длится ~20 минут; владелец согласился на потерю при рестарте |
| `rng` параметром в `start_game` | Детерминированные тесты раздачи без глобального `random.seed` |
| Клавиатура строится от состояния | Кнопка догадки исчезает в DOUBLE_AGENT, в голосовании нет выбывших |
| Проверки и в клавиатуре, и в движке | Старый callback из истории чата иначе ломает режим |
| `poetry config virtualenvs.create false` | Poetry ставит в `venv/` проекта, второе окружение не плодится |

## Открытия

1. `sqlalchemy[asyncio]` **не** тянет `greenlet` — пришлось добавить явно, иначе все async-тесты падают
2. `session.get()` отдаёт объект из кеша сессии без подгруженных связей → `MissingGreenlet`.
   Ловушка сработала дважды: в сидере и в `copy_to`. Лечение — `select` вместо `get`
3. Конфликт имён `word_card` в `texts.py` поймал ruff (F811), а не тесты
4. Пользовательский текст уходит в HTML без экранирования — воспроизведено, не исправлено
